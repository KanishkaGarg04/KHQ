A portfolio disguised as an engineering headquarters.

This isn't just a website that says "Hi, I'm Kanishka."

It's a place where projects are shipped, experiments fail, bugs become features, and questionable engineering decisions eventually become learning experiences.

...

The real story

Problem → Question → Debug → Break something else → Question → Fix → Learn → Ship.

And yes, this portfolio itself went through exactly that cycle.

At one point, the entire screen was just... white.

We investigated the router.

Then the server.

Then hydration.

Then TanStack Start.

Then Nitro.

Then Vercel.

Then the browser.

Then questioned every life decision that led here.

Eventually we discovered the simplest answer:

The portfolio didn't need all that complexity.

It just needed to render.

So we stripped the runtime back to what the portfolio actually needed:

Vite + React + TypeScript

And suddenly...

the portfolio was alive.

That's basically what this repository represents:

Build → Break → Investigate → Understand → Rebuild → Ship.

Not perfection.

Progress.
